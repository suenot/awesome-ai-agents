# Awesome AI Agents

Welcome to **Awesome AI Agents** — a curated list of frameworks, libraries, and tools for building your own AI agent systems. This repository focuses on solutions that enable multi-agent systems, tool integration (like MCP), and autonomous agent workflows. Whether you're a developer, researcher, or enthusiast, this collection will help you explore and create cutting-edge AI agents.

---

## About

**Awesome AI Agents** is a resource hub for discovering open-source and closed-source frameworks that empower you to build custom AI agent systems. These tools support multi-agent collaboration, external tool integration, and advanced reasoning capabilities.

- **Goal**: Provide a comprehensive list of libraries and frameworks for creating AI agents.
- **Focus**: Multi-agent systems, tool support (e.g., MCP), and flexibility.
- **Contributions**: We welcome your suggestions! See [Contributing](#contributing).

## Open-Source Frameworks

These libraries help you build custom AI agent systems with multi-agent capabilities and tool support:

- **[Agno](https://github.com/kyegomez/Agno)**  
  A Python framework for creating complex agentic workflows. Supports multi-agent collaboration, MCP integration, and tools like web search or APIs. Ideal for simplicity and scalability.
- **[PydanticAI](https://github.com/pydantic/pydantic-ai)**  
  A framework for building reliable AI agents with structured outputs using Pydantic. Offers MCP support and modular design for multi-agent systems.
- **[SmolAgents](https://github.com/huggingface/smolagents)**  
  A lightweight, modular framework for fast AI workflows. Supports multiple AI providers, tools, and multi-agent setups with built-in telemetry.
- **[Open Interpreter](https://github.com/KillianLucas/open-interpreter)**  
  Turns natural language commands into executable code. Supports tool integration and can be extended for multi-agent scenarios.
- **[LaVague](https://github.com/lavague-ai/LaVague)**  
  A framework for creating web agents that perform actions using LLMs. Supports tool use and multi-agent orchestration.
- **[AgentGPT](https://github.com/reworkd/AgentGPT)**  
  An open-source platform for autonomous agents. Can be customized for multi-agent systems and tool integration.

## Specialized Tools

These tools enhance agent systems with specific capabilities like browser interaction or computer use:

- **[Browser Use](https://github.com/anthropics/browser-use)**  
  Enables agents to interact with browsers programmatically. Useful for web-based multi-agent tasks with tool support.
- **[OpenManus](https://github.com/manus-ai/openmanus)**  
  An open-source agent framework for computer operation. Supports tools directly in code, reducing latency compared to MCP.

## Closed-Source Frameworks

Proprietary solutions that support tool integration and agent workflows:

- **[Claude Code](https://github.com/anthropics/claude-code)**  
  Anthropic's interactive coding agent with MCP support. Enhances coding workflows with natural language and external tools.
- **[Cursor IDE](https://cursor.sh)**  
  An AI-powered code editor with MCP integration. Supports agent-assisted coding and tool connections for enhanced productivity.
